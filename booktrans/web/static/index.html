How it works

The book is read page by page. Paragraphs, table cells and figure labels are translated; lines, curves and symbols are kept.

逐页处理：翻译段落、表格单元格和图中文字，保留线条、曲线和符号。

Privacy

Your API key lives in memory for one job only. Uploads and results are deleted automatically after 24 hours, or when you delete them.

API key 只在任务期间存于内存；文件 24 小时后自动删除。

Good to know

Cost is billed to your own key, roughly a few cents per page. Translation quality can vary; check important pages.

费用由你的 key 承担，大约每页几美分。翻译质量可能有差异，重要内容请自行核对。
