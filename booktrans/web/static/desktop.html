Your book is translated on this computer. Only the text goes to the model provider you choose, with your own API key. 书在本机处理，只有文字会发给你选择的模型供应商，并使用你自己的 API key。

§ 00

API key 接口密钥

Book text is sent to the provider you pick below, and nowhere else; the app has no server and no telemetry. You are responsible for having the right to translate the books you use. 书中文字只会发给下面选择的供应商，本应用没有服务器，也不收集数据；请确保你有权翻译所用的书。

Domestic and international Qwen keys are different; pick the site your key came from. 国内站与国际站的 key 不通用，请选择你申请 key 的站点。

How do I get a key? 如何获取 key？

Checked with the provider, then stored in your system's credential store (Windows Credential Manager); never written to a file or logged. 验证通过后保存在系统凭据库，不会写入文件或日志。

About

Book Translator, free software under the GNU AGPL-3.0. Source code: github.com/Youngodd/booktrans. It bundles PyMuPDF (AGPL, Artifex). 本软件以 AGPL-3.0 授权，源代码见上方链接。

Good to know

Cost is billed to your own key. Translation quality can vary; check important pages. Closing the app pauses a running book; open it again and press Continue.

费用由你的 key 承担。翻译质量可能有差异，重要内容请自行核对。关闭应用会暂停任务，再次打开后点“继续”。
