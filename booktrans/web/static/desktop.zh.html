§ 02

API key

书中文字只会发给下面选择的供应商，本应用没有服务器，也不收集数据；请确保你有权翻译所用的书。

国内站与国际站的 key 不通用，请选择你申请 key 的站点。

如何获取 key？

留空则使用系统代理设置；在中国大陆访问 Anthropic 通常需要代理。

验证通过后保存在系统凭据库（Windows 凭据管理器），不会写入文件或日志。
